  - **코드를 읽을 때는 `원본_코드만.html`(약 22KB)을 읽는다.** `점심메뉴_룰렛.html`(약 480KB)은 대부분 내장 폰트라 통째로 읽으면 토큰 낭비다. 원본 파일은 브라우저로 띄워 동작·화면을 비교할 때만 쓴다.
  - 글꼴은 Pretendard woff2 파일로 분리해 `client/fonts/`에 둔다(원본의 내장 폰트를 파일로 꺼내거나 공개 배포본 사용).
- 서버(Lightsail)에 올리기·도메인·HTTPS 설정(로드맵 0단계의 서버 부분, 3단계 배포)은 **사장님이 직접** 한다. 공장은 상자 안에서 만들고 시험하는 데까지 한다.
- 로드맵 단계대로 진행하고, 각 단계의 완료 기준을 통과해야 다음 단계로 넘어간다. 설계가 끝나면 사장님 승인을 받는다.

## 개요

점심, 회식, 커피처럼 상황별 메뉴판을 만들고, 여러 명이 각자 폰과 PC에서 같은 룰렛을 돌려 결과를 함께 기록하는 웹 앱(PWA)입니다. 원본 "점심 메뉴 룰렛"의 화면과 규칙을 그대로 옮기고 **그룹 공유, 메뉴판 여러 개, 확정 기록 보기** 세 가지를 더합니다.

- **앱 이름**: 한잔메뉴룰렛
- **대상**: 같이 먹고 마시는 동료, 친구, 가족 모임
- **해결하는 문제**: "뭐 먹지?" 고민을 줄이고, 어제 먹은 메뉴가 또 나오는 것을 막고, 모두가 같은 결과를 보게 합니다.

| 구분 | 내용 |
|---|---|
| 그대로 유지 | 룰렛 모양·회전 연출, 어제 메뉴·오늘 넘김 제외 규칙, 확정/다시 돌리기, 메뉴 추가·끄기·삭제, 소리, 스페이스바 |
| 새로 추가 | 그룹(초대 링크·코드), 메뉴판 여러 개와 템플릿, 확정 기록·통계, 폰 홈 화면 설치 |
| 이번에 제외 | 이메일 회원가입, 앱스토어 등록, 회전 장면 실시간 중계(2단계 후보) |

## 원본 룰렛 분석

원본은 서버 없이 브라우저 하나로 도는 단일 HTML(약 480KB, 대부분 내장 폰트) "점심 메뉴 룰렛"입니다. 핵심은 단순 무작위가 아니라 **어제 먹은 메뉴와 오늘 넘긴 메뉴를 자동으로 빼고 돌린다**는 점입니다.

### 화면 구성

| 영역 | 구성 요소 | 동작 |
|---|---|---|
| 상단 배지 | "오늘 점심 확정: ○○" | 오늘 확정한 메뉴가 있을 때만 표시 |
| 룰렛 | 원판(캔버스 900×900), 위쪽 빨간 포인터, 칸 경계의 못 | 칸 수에 따라 글자 크기 50/42/34px, 9자 이상 이름은 7자+… |
| 안내 문구 | 룰렛 아래 한 줄 | 후보가 부족할 때 이유 표시 |
| 돌리기 버튼 | 큰 빨간 버튼 + "스페이스바로도 돌릴 수 있어요" | 회전 중·후보 부족 시 비활성 |
| 메뉴 패널(오른쪽) | 목록(개수/16), 체크박스·이름·상태 태그·× | 태그: 오늘 확정 / 오늘 넘김 / 어제 먹음 |
| 메뉴 추가 | 입력칸(최대 20자) + 추가 버튼 | 16개 초과·중복 시 안내 |
| 하단 버튼 | 소리 켜짐/꺼짐, 처음 메뉴로 되돌리기 | 초기화는 확인창 후 실행 |
| 결과 카드 | "오늘 점심은" + 메뉴명 | 이걸로 확정 / 다시 돌리기 / 닫기 |

화면 폭 860px 이하에서는 룰렛 위, 메뉴 패널 아래로 세로 배치됩니다.

### 동작 규칙

1. **후보 고르기**: 켜진 메뉴에서 오늘 넘긴 메뉴와 어제(오늘 이전 가장 최근) 확정 메뉴를 뺍니다.
2. **부족할 때 완화**: 후보가 2개 미만이면 어제 메뉴를 다시 넣고, 그래도 1개면 돌리지 않고 바로 결과를 보여 줍니다. 0개면 오늘 넘김 기록을 비우고 처음부터 다시 계산합니다. 켜진 메뉴가 2개 미만이면 돌리기를 막습니다.
3. **회전**: 당첨 칸을 먼저 무작위로 정한 뒤, 그 칸 안 임의 위치(칸 폭의 ±35%)에 멈추도록 5~7바퀴를 5초간 돌립니다. 끝에서 살짝 지나쳤다 되돌아오는 감속 곡선을 씁니다.
4. **손맛 연출**: 포인터가 칸 경계를 지날 때마다 튕기고 "틱" 소리가 납니다. 결과가 나오면 3음 차임과 색종이 140조각이 4초간 떨어집니다.
5. **다시 돌리기**: 나온 메뉴를 "오늘 넘김"에 넣고 0.35초 뒤 자동으로 다시 돌립니다.
6. **확정**: 오늘 기록을 이 메뉴로 덮어쓰고(하루 1건), 오늘 넘김을 비웁니다. 기록은 최근 30건만 남깁니다.
7. **회전 중 잠금**: 돌아가는 동안 메뉴 패널은 반투명해지고 조작할 수 없습니다.

### 메뉴 관리

- 기본 메뉴 8개: 김치찌개, 제육볶음, 돈가스, 짜장면, 국밥, 비빔밥, 햄버거, 샐러드
- 최대 16개, 같은 이름 중복 불가, 체크 해제로 잠시 빼기 가능
- 삭제하면 5초 동안 "되돌리기" 알림이 뜹니다.

### 저장

브라우저 localStorage에 `lunchRoulette.v1.` 접두어로 4가지를 저장합니다. 같은 기기·같은 브라우저에서만 유지되고 다른 사람과 공유되지 않습니다.

| 키 | 내용 |
|---|---|
| items | 메뉴 목록 `[{name, on}]` |
| history | 확정 기록 `[{date, name}]`, 최근 30건 |
| skipped | 오늘 넘긴 메뉴 `{date, names}`, 날짜가 바뀌면 초기화 |
| sound | 소리 켜짐 여부, 기본 꺼짐 |

### 디자인

- 남색 바탕(#1B2A44), 종이색 글자(#F3EEE3), 도장 빨강 버튼(#C0392B)
- 룰렛 칸 8색 팔레트, 마지막 칸이 첫 칸과 같은 색이 되지 않게 조정
- Pretendard 폰트(500·700)를 파일 안에 내장해 오프라인에서도 같은 글꼴
- 키보드 포커스 표시, 움직임 줄이기 설정 시 결과 카드 애니메이션 생략

1단계는 원본 기능 전부 + 그룹 공유 + 메뉴판 여러 개 + 기록 보기입니다. 혼자 써도 불편하지 않은 기능은 2단계로 미뤘습니다.

| 룰렛 | 후보 규칙 | 원본 규칙(어제·넘김 제외, 부족 시 완화)을 메뉴판별로 적용, "어제 먹음" 제외는 메뉴판마다 끌 수 있음 | 1단계 |

| 기록 | 기록 목록 | 메뉴판별 날짜·메뉴·확정한 사람, 최근 30일 기본, 더 보기 | 1단계 |
| 기록 | 통계 | 기간(30일·90일·전체)별 메뉴 횟수 막대 | 1단계 |
| 기록 | 기록 고치기 | 잘못 확정한 날의 기록 수정·삭제 | 2단계 |
| 기록 | 내보내기 | 기록을 CSV 파일로 저장 | 2단계 |
| 설치 | 홈 화면 설치 | 앱 아이콘, 전체 화면 실행, 폰·PC 모두 | 1단계 |
| 설치 | 업데이트 안내 | 새 버전이 있으면 "새로고침" 알림 | 2단계 |

### 공유할 때의 규칙

- **날짜 기준**: 기기 시간대와 관계없이 한국 시간 자정(00:00)에 하루가 바뀝니다. 멤버마다 "어제"가 달라지는 일을 막기 위해서입니다.
- **하루 1건**: 한 메뉴판에 하루 확정 기록은 1건입니다(원본과 동일). 점심판과 한잔판은 따로 셉니다.
- **당첨 결정**: 돌린 사람의 기기에서 정합니다. 결과 카드는 돌린 사람에게만 뜨고, 확정하면 모두에게 "오늘 확정" 배지가 뜹니다.
- **오늘 넘김 공유**: 누구든 "다시 돌리기"로 넘긴 메뉴는 그 메뉴판의 모든 멤버에게 빠집니다.
- **동시 확정**: 먼저 저장된 쪽이 남고, 늦은 쪽에는 덮어쓰기 확인창을 띄웁니다.
- **권한**: 모든 멤버가 메뉴판과 메뉴를 고칠 수 있고, 그룹 삭제만 만든 사람이 합니다.

## 화면 구성 및 사용자 흐름

메인 화면은 원본 배치(왼쪽 룰렛, 오른쪽 메뉴 패널)를 그대로 두고, 위쪽에 그룹 이름과 메뉴판 탭 줄만 더합니다. 폰(폭 860px 이하)에서는 원본처럼 룰렛 아래로 패널이 내려가고, 탭은 가로로 밀어 넘깁니다.

| 화면 | 들어가는 곳 | 주요 요소 |
|---|---|---|
| 시작 | 처음 실행, 초대 링크 | 그룹 만들기, 코드 입력, 닉네임 |
| 룰렛(메인) | 앱을 열면 바로 | 메뉴판 탭, 오늘 확정 배지, 룰렛, 돌리기, 메뉴 패널(원본과 동일) |
| 결과 카드 | 회전이 끝나면 | 메뉴판의 결과 문구 + 메뉴명, 확정 / 다시 돌리기 / 닫기 |
| 기록 | 상단 "기록" 버튼 | 메뉴판 선택, 날짜별 목록(확정한 사람 포함), 메뉴별 횟수 막대 |
| 메뉴판 관리 | 탭 줄의 "+" 또는 탭 길게 누르기 | 이름, 결과 문구, 시작 템플릿, "어제 먹음" 제외 켜기·끄기, 삭제 |
| 그룹 설정 | 상단 그룹 이름 | 초대 링크 복사·코드, 멤버 목록, 나가기 |

**사용자 흐름** (누가 돌려 확정하든 그룹 모두의 화면에 반영됩니다):
앱 열기(처음이면 시작 화면) → 그룹 만들기(또는 링크로 참여) → 닉네임 정하기(회원가입 없음) → 메뉴판 고르기(없으면 템플릿으로) → 룰렛 화면(메뉴 켜기·끄기) → 돌리기(어제·넘김 빼고 회전) → 결과 카드(돌린 사람에게만) → **이걸로 확정**(기록 저장·실시간 반영, 내일은 어제 메뉴로 제외)
- 결과 카드에서 "다시 돌리기" → 넘김 추가 후 곧바로 다시 돌리기
- 결과 카드에서 "닫기" → 아무것도 저장하지 않고 룰렛 화면으로

## 데이터 구조와 저장 방식

공유 데이터는 Lightsail 서버의 SQLite DB 파일 하나에, 기기별 설정만 브라우저에 저장합니다. 모든 읽기·쓰기는 서버 API를 거치고, 서버가 기기 토큰으로 그룹 멤버인지 확인합니다.

| 테이블 | 담는 내용 | 비고 |
|---|---|---|
| groups | id, name, invite_code, owner_member_id, created_at | 초대 코드는 무작위 6자리 |
| members | id, group_id, nickname, token_hash, joined_at | 토큰 원문은 기기에만, 서버엔 해시만 저장 |
| boards | id, group_id, name, result_lead, template, exclude_yesterday, sort_order, updated_at | exclude_yesterday 기본 켜짐 |
| items | id, board_id, name, is_on, sort_order | 메뉴판당 최대 16개, 같은 이름 중복 불가 |
| skipped | board_id, date, name | 오늘 넘긴 메뉴, 날짜가 지난 행은 무시 |
| history | board_id, date, name, member_id, confirmed_at | (board_id, date) 유일 → 하루 1건 보장 |
| 기기 localStorage | token, nickname, sound, lastGroupId, lastBoardId | 원본처럼 접근을 try/catch로 감쌈 |

- **날짜 계산**: 서버가 한국 시간 자정 기준으로 "오늘"을 정합니다. 기기 시계가 틀려도 멤버 모두 같은 날짜를 봅니다.
- **어제 메뉴**: history에서 오늘 이전 가장 최근 1건입니다(원본과 동일). 메뉴판의 exclude_yesterday가 꺼져 있으면 빼지 않습니다.
- **기록 보관**: 원본은 30건만 남기지만, 기록 보기를 위해 제한 없이 보관하고 화면에는 최근 30일부터 보여 줍니다.
- **동시 확정**: (board_id, date) 유일 제약 때문에 두 번째 저장은 실패하고, 그 사람에게 덮어쓰기 확인창을 띄웁니다.
- **변경 알림**: 저장이 성공하면 서버가 같은 그룹에 접속한 기기들에 WebSocket으로 바뀐 내용을 보냅니다.
- **백업**: DB가 파일 하나라 하루 한 번 복사해 두고, Lightsail 스냅샷을 함께 씁니다.

## 기술 스택과 배포 형태

사용 중인 Lightsail 서버 한 대에 화면 파일, API 서버, DB를 모두 올립니다. 화면과 서버를 모두 JavaScript로 쓰고, 화면은 원본 코드를 최대한 재사용합니다.

| 영역 | 선택 | 이유 |
|---|---|---|
| 화면 | HTML · CSS · 바닐라 JavaScript(ES 모듈) | 원본 코드를 그대로 옮길 수 있고 빌드 과정이 없음 |
| 룰렛 | Canvas 2D | 원본 그리기·회전 코드 재사용 |
| API 서버 | Node.js + Express | 화면과 같은 언어, 작은 앱에 충분 |
| 실시간 반영 | WebSocket(Socket.IO) | 다른 멤버의 변경을 서버가 즉시 보내 줌, 끊기면 자동 재연결 |
| DB | SQLite(better-sqlite3) | 파일 하나라 설치·백업이 쉽고 소규모 그룹에 충분 |
| 사용자 구분 | 기기 토큰 | 처음 참여할 때 서버가 무작위 토큰을 발급, 회원가입 없음 |
| 웹 서버·HTTPS | Nginx + Let's Encrypt 인증서 | PWA 설치에 HTTPS가 필수, 인증서는 무료·자동 갱신 |
| 실행 관리 | PM2 | 서버가 재부팅돼도 앱 자동 실행 |
| 앱 설치 | manifest.json + 서비스 워커 | 홈 화면 아이콘, 앱 파일·마지막 메뉴판 캐시로 오프라인 실행 |
| 글꼴 | Pretendard woff2 파일 분리 | 원본은 480KB 대부분이 내장 폰트, 파일로 분리해 캐시 |

- **Lightsail 설정**: 고정 IP를 연결하고(모든 플랜에 포함), 네트워킹 방화벽에서 80·443 포트를 엽니다. 도메인의 DNS를 이 IP로 연결해야 HTTPS 인증서를 받을 수 있습니다. *(사장님이 직접 함)*
- **오프라인 확정**: 연결이 없을 때의 확정은 기기에 대기시켜 두었다가 다시 연결되면 보냅니다. 그사이 다른 사람이 확정했으면 덮어쓰기 확인창을 띄웁니다.
- **보안**: 그룹 데이터는 그 그룹 토큰을 가진 기기만 읽고 쓸 수 있습니다. 초대 코드 입력은 횟수를 제한해 무작위 대입을 막습니다.

### 파일 구성(가안) — 공장에서는 최상위를 `apps/hanjan-roulette/`로

