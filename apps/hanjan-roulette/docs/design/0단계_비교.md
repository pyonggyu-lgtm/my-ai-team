# 0단계 비교 결과 (진사, 2026-11-05)

원본 `docs/reference/점심메뉴_룰렛.html`(브라우저로 연 파일)과 새 화면(`node tools/serve.mjs` → `http://localhost:8080/`)을 같은 크롬(headless, 한글 글꼴 설정 적용)에서 비교했다.

**결론: 시험 C 4/4 일치, 시험 D 23/23 같음, 시험 E 통과.** 실패한 시험은 없다. 참고 사항 1건(아래 "참고")이 있다.

## 시험 C — 캔버스 픽셀 (`tests/e2e/compare-canvas.mjs`)

각 페이지 localStorage(`lunchRoulette.v1.items`)에 같은 값을 넣고 새로고침 → `document.fonts.ready` + `fonts.load("700 40px Pretendard")` + 0.6초 대기 → `#wheel.toDataURL()` 전체 문자열 비교.

| 상태 | 결과 | 다른 픽셀 | 글자 그리기 호출(원본/새) |
|---|---|---|---|
| 메뉴 8개(기본) | 일치 | 0 | 8 / 8 |
| 메뉴 12개 | 일치 | 0 | 12 / 12 |
| 메뉴 16개 | 일치 | 0 | 16 / 16 |
| 켜진 메뉴 1개 ("메뉴를 켜 주세요") | 일치 | 0 | 1 / 1 |

- 글자가 실제로 그려졌는지(빈 글자로 맞은 것이 아닌지) 확인했다: 한글이 정상으로 보인다. 캡처 `0단계_캡처/C-{8,12,16,on1}-{orig,new}.png`. 원본 결과 `C_result.json`.

## 시험 D — 점검표 23항목 (`tests/e2e/checklist.mjs`, 결과표는 `tests/e2e/0단계_점검표.md`)

23항목 모두 "같음". 방법과 허용 오차는 점검표 머리글에 적었다. 눈여겨볼 관측값(원본 = 새 화면):

| 항목 | 값 |
|---|---|
| 3 회전 시간 | 원본 5023ms / 새 5021ms, 회전 끝과 카드 표시는 같은 순간(0ms) |
| 4 회전 중 패널 | opacity 0.5, pointer-events none, 체크박스 자리 클릭이 패널에 닿지 않음 |
| 6 포인터 튕김 | 최소값 −0.425(= −0.5×0.85) 동일, 마지막 프레임 0 |
| 7 소리 | 켤 때 900Hz·0.03초·볼륨 0.06 한 번, 차임 660/880/1100Hz(0·0.16·0.32초 시작, 0.18·0.18·0.3초 길이, 볼륨 0.1) 동일. 회전 중 틱 횟수 58 / 60(프레임 타이밍 차이, 허용 ±8 안) |
| 9 색종이 | 카드가 뜬 0.4초 뒤 그려짐, 4.5초 뒤 지워짐, 캔버스 크기=창 크기 |
| 11 다시 돌리기 | 자동 회전까지 352ms / 352ms, 누른 직후 해당 메뉴에 "오늘 넘김" |
| 18 삭제 | 「돈가스」를 지웠어요 + 되돌리기, 4.5초 뒤 보임·5.4초 뒤 사라짐 |
| 19 확인창 | 두 화면 모두 `메뉴를 처음 8개로 되돌릴까요? 지금 목록은 사라져요.` (취소하면 그대로, 확인하면 처음 8개) |
| 20 긴 이름 | 9자 → `가나다라마바사…`, 8자는 그대로 |
| 21 폭 | 390px 한 줄 배치(메뉴판이 룰렛 아래, 가로 스크롤 없음), 860px=1열, 861px=2열 |
| 22 움직임 줄이기 | 카드 animation-name 원본·새 모두 `none`(기본 설정에서는 `rise`), 회전은 5초 그대로 |

- 두 화면에 `Math.random`을 같은 시드로 넣었는데 **멈춘 메뉴·확정 메뉴·넘긴 메뉴가 모두 같았다.** 즉 난수를 부르는 순서(칸 → 흔들림 → 바퀴 수)도 원본과 같다.
- 정지 화면 전체 픽셀 비교(`compare-shots.mjs`): 첫 화면 1440×900, 모바일 390×844 모두 다른 픽셀 0.
- 캡처: `0단계_캡처/D-01-첫화면`, `D-02-회전중`, `D-03-결과카드`, `D-04-모바일390` 의 `-orig.png`/`-new.png`. 항목별 관측값 전체는 `D_result.json`.

## 시험 E — 글꼴 (`tests/e2e/fonts-check.mjs`)

- 새 화면 네트워크: `/fonts/Pretendard-Bold.woff2` 200, `/fonts/Pretendard-Medium.woff2` 200 (둘 다 `font/woff2`).
- `document.fonts.check("700 40px Pretendard")` = true, `("500 20px Pretendard")` = true, 두 글꼴 모두 `loaded`. 결과 `E_result.json`.

## 참고 (시험 실패 아님, 진록 판단 필요)

- 새 화면은 브라우저가 자동으로 요청하는 `/favicon.ico`가 404라서 콘솔에 "Failed to load resource … 404" 오류가 한 줄 남는다(원본은 `file://`로 열어 요청이 없다). `client/index.html`에 아이콘 링크가 없고 `client/`에도 아이콘 파일이 없기 때문이다. 동작에는 영향이 없고 3-1(앱 아이콘)에서 해결될 일이다. 0단계에서 조용히 하려면 진오가 빈 `<link rel="icon" href="data:,">`를 넣으면 된다(내 담당 밖이라 손대지 않음).
- 점검표의 소리 시험은 실제 소리가 아니라 `AudioContext` 호출 기록으로 비교했다(지시서대로). 귀로 듣는 확인은 하지 않았다.
