  예: `grep -o 'base64,[A-Za-z0-9+/=]*' 원본 | sed -n '1p' | cut -c8- | base64 -d > ...` (출력을 화면에 찍지 말 것)

## 진오 (Pane 4) — 작업 0-1(package.json), 0-4, 0-5, 0-6

### 0-1 `package.json`
- `{"name":"hanjan-roulette","private":true,"type":"module","scripts":{"start":"node tools/serve.mjs","test":"node --test tests/unit/"}}` — dependencies 없음. (`node --test tests/unit/`가 Node 22에서 폴더를 못 받으면 `node --test "tests/unit/*.test.js"`로.)

### 0-4 `client/index.html`, `client/js/{wheel,pool,effects,app}.js`
- `index.html`: 원본 2–7줄의 head + `<link rel="stylesheet" href="css/style.css">` + 97–132줄 마크업 그대로 + `<script type="module" src="js/app.js"></script>`. title은 원본 그대로 "점심 메뉴 룰렛".
- 글꼴 미리 받기 `<link rel="preload" href="fonts/Pretendard-Bold.woff2" as="font" type="font/woff2" crossorigin>` 정도는 넣어도 됨(동작에 영향 없음).
- `pool.js`: `yesterdayName(history, today)`, `todayConfirmed(history, today)`, `computePool({items, skippedNames, yesterday, excludeYesterday=true})`, `itemTag(item, {confirmed, skippedNames, yesterday})` — **순수 함수**(DOM·localStorage 없음). 원본 195줄의 넘김 비우기는 `resetSkipped:true`로 돌려주고, 메시지는 원본 197줄과 똑같이 합성.
- `wheel.js`: `PALETTE, FONT, TAU, SPIN_SEC, mod, ease, segColor, shortName, indexUnderPointer(theta,n), planSpin(theta,n,rng=Math.random) → {k, delta}, drawWheel(ctx,names,theta,pointerKick), animateSpin({ctx,names,from,delta,onTick}) → Promise<finalTheta>`. `planSpin`은 원본 288–291줄의 난수 호출 **순서**(k → jitter → 바퀴 수) 그대로. `animateSpin`은 원본 296–307 프레임 루프 그대로(포인터 튕김 `-0.5`, 감쇠 `0.85`, 마지막 프레임 정확히 `from+delta`).
- `effects.js`: `setSound(on)`, `tick()`, `chime()`, `startConfetti(canvas)`, `stopConfetti()`. `PALETTE`는 wheel.js에서 import.
- `app.js`: 나머지 전부(상태·`lunchRoulette.v1.` 저장·render·결과 카드·목록·삭제 되돌리기·추가·초기화·소리·스페이스바·글꼴 로드 후 다시 그리기). spin 흐름은 설계 2.3 마지막 줄. `body.busy`, `#spin.disabled`, 0.35초 재회전, `confirm` 문구 모두 원본과 같게.
- 0단계 날짜는 원본 `todayStr()`(기기 시간) 그대로.

### 0-5 `tools/serve.mjs`
- 의존성 없음(`node:http`, `node:fs`, `node:path`). `client/`를 기본 8080 포트로 제공(`PORT` 환경 변수로 변경 가능), `/` → `index.html`, MIME: html, css, js(`text/javascript`), woff2, json, png, svg, ico. 경로 탈출(`..`) 막기, 없는 파일 404.

### 0-6 단위 시험 (`node --test`)
- `tests/unit/pool.test.js`: 설계 3.1 A의 갈래 **12건 이상**, 문구는 원본 문자열과 정확히 비교.
