## 3-2·3-3 진오
### index.html·앱 (진오 소유)
- `<head>`에 `<link rel="manifest" href="manifest.json">`, `<meta name="theme-color" content="#1B2A44">`, `<link rel="icon" href="icons/icon-192.png" type="image/png">`, `<link rel="apple-touch-icon" href="icons/icon-192.png">`, `<meta name="apple-mobile-web-app-title" content="한잔룰렛">`. (favicon 404 해결 — HANDOFF 2절)
- 서비스 워커 등록(`navigator.serviceWorker.register("sw.js")`, 지원 안 하면 조용히 넘김).

### sw.js
- 캐시 이름에 버전: 예 `const CACHE = "hanjan-v1"` 한 곳에서만 정의(시험 ③에서 바꿔 끼움).
- install: 앱 파일 목록(index.html, css, js 전부, views/, fonts 2개, manifest, icons 4개)을 `cache: "reload"`로 받아 미리 저장, `skipWaiting()`.
- activate: `hanjan-`로 시작하고 현재 이름이 아닌 캐시 전부 삭제 → `clients.claim()`.
- fetch: 같은 출처 GET만 처리. `/api/`, `/socket.io/`는 **건드리지 않음(네트워크만)**. 페이지 이동(navigate)은 쿼리 무시하고 `index.html`로 응답(`?join=` 링크 오프라인에서도 열리게). 나머지는 cache-first, 없으면 네트워크.
- 업데이트 안내 알림은 4단계(만들지 않음).

### 서버 시작점 (설계 7장 15번: .env에 포트·DB 경로)
- `server/index.js`의 직접 실행 부분이 `PORT`, `HOST`, `DB_PATH`를 환경 변수로 읽게(없으면 지금 기본값 그대로 — 개발·시험 동작 불변). 배포에선 Nginx가 정적 파일을 주므로 `STATIC_DIR`가 비어 있으면… 지금처럼 client/를 주어도 무방(127.0.0.1 바인딩이라 외부 노출 없음). 판단 어려우면 지금 동작 유지.
- `.env` 읽기는 패키지 없이 Node 22 `--env-file`(PM2 `node_args`)로.

### deploy/ 파일
- `deploy/nginx.conf`: 80→443 리다이렉트, 443 HTTPS(certbot 경로·`options-ssl-nginx.conf`·`ssl-dhparams.pem`), `root /srv/hanjan/client`, `/api/`와 `/socket.io/`는 `127.0.0.1:{PORT}` 프록시(Upgrade/Connection 헤더, `X-Forwarded-For`·`X-Real-IP`·`X-Forwarded-Proto`, 소켓 read timeout 넉넉히), `/`는 `try_files $uri $uri/ /index.html`.
  - **보안 헤더**(HANDOFF 2절): HSTS, `X-Content-Type-Options nosniff`, `Referrer-Policy`, `X-Frame-Options DENY`(또는 CSP frame-ancestors), `Permissions-Policy`, CSP(`default-src 'self'` 기준, 실제 앱이 쓰는 것만 열기 — inline 스크립트·스타일 있는지 확인하고 결정). 모두 `always`. **`add_header`가 있는 location 안에서는 바깥 헤더가 상속되지 않는 점** 주의(공통 헤더는 include 조각 또는 location마다 반복).
  - 캐시: `sw.js`·`index.html`·`manifest.json`은 `Cache-Control: no-cache`. 나머지 정적 파일은 짧게 또는 no-cache(파일명에 해시가 없으므로 오래 캐시 금지).
  - `server_tokens off`, `client_max_body_size 1m`(그룹 만들기 bigJson 1mb).
  - favicon.ico 요청 처리(아이콘으로 넘기거나 로그 끔).
- `deploy/ecosystem.config.js`: 앱 이름 `hanjan`, `cwd /srv/hanjan`, `script server/index.js`, **`instances: 1`, fork 모드**(Socket.IO 방·시도 제한이 메모리에 있음), `node_args: "--env-file=.env"`, `NODE_ENV=production`, 재시작 정책, 로그 경로. 비밀값 없음. (package.json이 `"type":"module"`이므로 `.js` 설정 파일이 ESM으로 읽힐 수 있음 — PM2 7에서 읽히는지 확인, 안 되면 `.cjs` 필요 여부를 진록에게 보고)
- `deploy/backup.sh`: SQLite 안전 복사(WAL 쓰는 중에도 안전한 방식 — 서버에 `sqlite3` CLI가 없으므로 이미 설치되는 `better-sqlite3`의 `backup()` 사용), `/srv/hanjan-data/backups/hanjan-YYYYMMDD-HHMM.db`, 14일 넘은 백업만 정리(이 스크립트 안의 정리 동작은 설계 3-3 범위), `set -euo pipefail`, 권한 600. 경로는 `.env`의 `DB_PATH`를 읽거나 인자로.
- `.env.example`(앱 루트): `PORT=`, `HOST=`, `DB_PATH=` 등 **값 비움**, 각 줄 위에 설명 주석.
- `.gitignore`에 `.env` 추가(`.env.example`은 제외되지 않게).

### 시험 스크립트 (진오 작성·실행)
`tests/e2e/3단계_시험.mjs` — 개발 서버(임시 DB)를 띄우고 headless Chromium으로:
- ① manifest 필수 항목·아이콘 4개 실제 크기 확인, `navigator.serviceWorker.controller` 존재(새로고침 후).
- ② `context.setOffline(true)` → 새로고침 → 화면 열림, 돌리기 동작, 그룹 상태에서 확정 → `hanjan.v1.outbox`에 들어감. `?join=` 주소도 오프라인으로 열림.
- ③ sw.js 캐시 이름을 바꿔 제공(route로 바꿔 끼우기) → 다시 띄우면 `caches.keys()`에 새 이름만 남음.
- favicon: 페이지 열 때 404 응답이 하나도 없음.
- 기존 시험(`npm test`, `npm run test:server`, `test:tz`)도 전부 다시 GREEN 확인.
- 완료 시 진록에게 보고(바꾼 파일 목록 + 시험 결과 숫자).
