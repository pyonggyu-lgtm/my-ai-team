## 1. 코드 올리기 (사장님 PC — 바깥 Ubuntu)

공장 산출물을 커밋한 뒤:

```bash
git push origin main
```

## 2. 서버에 코드 받기 (서버 — Lightsail 브라우저 SSH)

```bash
# /srv/hanjan 이 비어 있는지 확인 (비어 있어야 clone 됨)
ls -A /srv/hanjan

cd /srv/hanjan
git clone --filter=blob:none --no-checkout https://github.com/pyonggyu-lgtm/my-ai-team.git .
git sparse-checkout set apps/hanjan-roulette
git checkout main
git config core.quotepath false

# 받은 것 확인: apps/hanjan-roulette 아래 client, server, deploy 가 보여야 함
ls apps/hanjan-roulette
```

- 저장소가 **비공개**면 clone 때 사용자 이름과 비밀번호를 묻습니다. 비밀번호 자리에는 GitHub에서 만든 **읽기 전용 토큰**(Fine-grained, 이 저장소만, Contents: Read-only)을 서버 화면에 직접 입력하세요. 채팅·문서에는 붙이지 않습니다.
- 저장소 맨 위의 파일 몇 개(README.md, package.json 등)도 같이 받아집니다(sparse checkout의 기본 동작). 비밀 파일은 저장소에 없으므로 괜찮습니다.

## 3. 패키지 설치

```bash
cd /srv/hanjan/apps/hanjan-roulette
npm ci --omit=dev

# better-sqlite3(기계어 빌드)가 잘 들어갔는지 확인 → "ok" 가 나와야 함

```

빌드 오류가 나면 오류 마지막 20줄을 공장에 가져와 주세요(대비책: `node:sqlite`로 바꾸는 것은 `server/db.js` 한 파일만 바뀜).

## 4. `.env` 직접 만들기

```bash
cd /srv/hanjan/apps/hanjan-roulette
[ -f .env ] || cp .env.example .env 2>/dev/null || touch .env   # .env 가 이미 있으면 그대로 둠(덮어쓰기 방지). 없으면 견본 복사, 견본도 없으면 빈 파일
chmod 600 .env
nano .env
```

`nano`에서 세 키의 값을 아래처럼 채우고 `Ctrl+O` → Enter → `Ctrl+X`:

```
PORT=3000
HOST=127.0.0.1
DB_PATH=/srv/hanjan-data/hanjan.db
```

- 먼저 3000번을 다른 서비스(hermes 등)가 쓰고 있지 않은지 확인: `sudo ss -ltnp | grep ':3000 '` → 아무것도 안 나와야 함.
- `HOST`는 꼭 `127.0.0.1`로 둡니다(밖에서 3000번으로 직접 못 들어오게).
- 포트를 3000이 아닌 값으로 바꾸면 `deploy/nginx.conf`의 `127.0.0.1:3000`(upstream 한 곳)도 같이 바꿔야 합니다.
- 앱이 읽는 값은 이 세 개뿐입니다(`server/index.js`). 비밀값은 없습니다.

## 5. Nginx 설정 넣기

### 5-1. 지금 설정 확인 (중요)

지금은 certbot이 `/etc/nginx/sites-enabled/default`에 인증서를 붙여 둔 상태입니다. 새 설정과 같은 주소(`hanjan.pygprg.com`)를 두 번 쓰면 충돌하므로, 기본 설정을 끄기 전에 **다른 서비스가 거기 들어 있지 않은지** 먼저 봅니다.

```bash
grep -nE 'server_name|proxy_pass|listen' /etc/nginx/sites-enabled/default
ls -l /etc/nginx/sites-enabled/
```

- `server_name`이 `hanjan.pygprg.com`(또는 `_`)뿐이고 `proxy_pass`가 없으면 → 5-2로.
- 다른 주소나 `proxy_pass`(예: hermes용)가 보이면 → **멈추고** 결과를 공장에 가져와 주세요.

### 5-2. 새 설정 연결

```bash
cd /srv/hanjan/apps/hanjan-roulette
sudo cp deploy/nginx.conf /etc/nginx/sites-available/hanjan
sudo ln -s /etc/nginx/sites-available/hanjan /etc/nginx/sites-enabled/hanjan

# 기본 설정 끄기: sites-enabled 의 '연결(링크)'만 빼는 것. 원본 /etc/nginx/sites-available/default 는 그대로 남음
sudo unlink /etc/nginx/sites-enabled/default

# 화면 파일을 Nginx(www-data)가 읽을 수 있는지 → "읽기 가능" 이 나와야 함
sudo -u www-data test -r /srv/hanjan/apps/hanjan-roulette/client/index.html && echo 읽기 가능

sudo nginx -t
```

`nginx -t`가 `syntax is ok` / `test is successful`이면:

```bash
sudo systemctl reload nginx
sudo certbot renew --dry-run    # 새 설정에서도 인증서 자동 갱신이 되는지 확인
```

- `nginx -t`가 실패하면 **reload 하지 말고** 오류 줄을 공장에 가져와 주세요. 되돌리기: `sudo unlink /etc/nginx/sites-enabled/hanjan && sudo ln -s /etc/nginx/sites-available/default /etc/nginx/sites-enabled/default && sudo nginx -t && sudo systemctl reload nginx`.
- 이 단계까지는 앱 서버가 아직 안 떠 있으므로 화면은 열리지만 그룹 기능은 502가 정상입니다.

## 6. 앱 서버 실행 (PM2)

```bash
cd /srv/hanjan/apps/hanjan-roulette
mkdir -p /srv/hanjan-data/logs      # PM2 로그 자리 (hanjan-out.log, hanjan-error.log)
pm2 start deploy/ecosystem.config.js
pm2 ls                       # hanjan 이 online 이어야 함
pm2 logs hanjan --lines 20   # "한잔메뉴룰렛 서버: http://127.0.0.1:3000" 줄 확인, Ctrl+C 로 나옴
sudo ss -ltnp | grep ':3000 '                 # node 가 3000 을 듣고 있어야 함
curl -s http://127.0.0.1:3000/api/health ; echo
```

- 설정은 PM2가 `/usr/bin/node --env-file=.env server/index.js`를 **그대로 실행**하게 되어 있습니다(`interpreter: "none"`). PM2가 자기 실행기로 `server/index.js`를 불러오면 서버의 "직접 실행" 조건이 맞지 않아, online인데 포트가 안 열리기 때문입니다.
- **포트가 안 열리면** `pm2 logs hanjan --lines 50` 과 `sudo ss -ltnp | grep 3000` 으로 확인하세요.

**이미 임시 방식으로 띄워 둔 서버라면**(`pm2 start /usr/bin/node --interpreter none -- --env-file=.env server/index.js` 로 띄운 경우) 설정 파일 방식으로 바꿉니다:

```bash
cd /srv/hanjan/apps/hanjan-roulette
git pull                                   # 고친 deploy/ecosystem.config.js 받기
pm2 ls                                     # 임시로 띄운 항목의 이름 확인(hanjan 이 아니면 아래 이름을 그것으로)
pm2 delete hanjan                          # 임시 항목 내리기 (PM2 목록에서만 빠짐, 파일·DB는 그대로)
pm2 start deploy/ecosystem.config.js
pm2 ls ; sudo ss -ltnp | grep ':3000 ' ; curl -s http://127.0.0.1:3000/api/health ; echo
pm2 save                                   # 재부팅 때 되살릴 목록을 새 설정으로 갱신 (꼭 다시 실행)
```

로그 회전 켜기(요청마다 로그가 한 줄씩 쌓여 디스크가 차지 않게, 서버에 한 번만):

```bash
pm2 install pm2-logrotate    # PM2 모듈 설치. 기본값: 로그 파일 10MB마다 잘라 30개까지 보관
```

자동 실행 등록:

```bash
pm2 save
pm2 startup
# ↑ 마지막에 "sudo env PATH=... pm2 startup systemd -u ubuntu --hp /home/ubuntu" 같은 한 줄이 나옵니다.
#   그 줄을 그대로 복사해 실행하세요.
```

재부팅 후 자동 실행 확인(다른 서비스 hermes도 같이 재시작되니 사용이 적은 시간에):

```bash
sudo reboot
# 1~2분 뒤 다시 접속해서
pm2 ls                       # hanjan online
docker ps                    # hermes 컨테이너도 다시 떠 있는지
```

## 7. 백업 등록

```bash
cd /srv/hanjan/apps/hanjan-roulette
chmod +x deploy/backup.sh

# 한 번 직접 돌려 보기 → 백업 파일이 생겨야 함
deploy/backup.sh
ls -l /srv/hanjan-data/backups/
```

서버 시간대 확인 후 하루 한 번 등록(사용이 적은 **한국 새벽 3시** 기준):

```bash
timedatectl | grep 'Time zone'
crontab -e
```

맨 아래에 한 줄 추가(시간대가 `Etc/UTC`일 때 = 한국 03:00):

```
0 18 * * * /srv/hanjan/apps/hanjan-roulette/deploy/backup.sh >> /srv/hanjan-data/logs/backup.log 2>&1
```

시간대가 `Asia/Seoul`이면 앞부분을 `0 3 * * *`로 쓰세요.

- 백업은 14일이 지난 것부터 자동 정리됩니다.
- Lightsail 자동 스냅샷: 콘솔 → 인스턴스 → 스냅샷 → 자동 스냅샷. **유료**(스냅샷 용량만큼 월 요금)이니 요금 확인 후 결정하세요.

## 9. 나중에 새 버전 올리기

```bash
cd /srv/hanjan/apps/hanjan-roulette
git pull
npm ci --omit=dev            # package-lock.json 이 바뀌었을 때만 필요(해도 무방)
pm2 reload hanjan
# nginx.conf 가 바뀐 경우에만:
sudo cp deploy/nginx.conf /etc/nginx/sites-available/hanjan && sudo nginx -t && sudo systemctl reload nginx
```

- 화면 파일이 바뀌는 커밋에서는 공장이 `client/sw.js`의 캐시 이름(버전)을 올려 둡니다. 그래야 폰이 옛 화면을 붙잡지 않습니다. 폰에서는 앱을 한 번 닫았다 열면 새 버전이 됩니다.
- 되돌리기: `git log --oneline | head` 로 이전 커밋을 보고 `git checkout <해시>` → `pm2 reload hanjan` (다시 최신으로: `git checkout main`).

## 10. 문제가 생기면

| 증상 | 볼 곳 |
|---|---|
| `nginx -t` 실패 | 오류 줄 번호와 문구를 공장에 가져오기. 설정은 Nginx 1.24 기준으로 썼음(`nginx -v`로 버전 확인) |
| 502 Bad Gateway | `pm2 ls`, `pm2 logs hanjan --lines 50` (앱 서버가 꺼졌거나 `.env` 포트 불일치) |
| PM2는 online인데 포트가 안 열림 | `pm2 logs hanjan --lines 50`, `sudo ss -ltnp \| grep 3000`. `pm2 describe hanjan` 에서 script path 가 `/usr/bin/node`, interpreter 가 `none` 인지 확인(아니면 위 6장 '이미 임시 방식으로…' 절차로 다시 시작) |
| 앱이 바로 꺼짐 | `pm2 logs hanjan` — `.env` 없음, `DB_PATH` 폴더 권한(`ls -ld /srv/hanjan-data` → ubuntu 소유 700) |
| 실시간 반영 안 됨 | `sudo tail -50 /var/log/nginx/error.log`, 브라우저 개발자 도구에서 `/socket.io/` 연결 |
| 화면이 옛 버전 | 폰에서 앱 완전히 닫고 다시 열기, 그래도면 공장에 알림(캐시 이름 확인) |
| 인증서 오류 | `sudo certbot certificates`, `sudo certbot renew --dry-run` |

공장에 가져올 때는 오류 문구만 복사해 주세요. `.env` 내용·토큰은 붙이지 않습니다.
