# 오늘 뭐 먹지? 🍻 — 식당 룰렛

친구들과 한잔할 식당을 정할 때, 각자 후보 식당을 추가하고 룰렛을 돌려 정하는 실시간 미니 앱입니다.

## 특징

- 각자 스마트폰에서 접속해 독립적으로 사용 (Supabase 등 외부 DB 없이 서버의 JSON 파일로 저장)
- 닉네임을 입력하면 자신이 추가한 식당에 이름표가 붙고, 본인이 추가한 항목만 삭제할 수 있습니다.
- 한 명이 룰렛을 돌리면 Socket.IO로 모든 접속자에게 실시간으로 같은 결과가 보여집니다.
- 룰렛은 현재 등록된 모든 식당을 동일한 확률로 포함합니다 (사람이 아닌 식당 기준 균등 확률).

## 실행 방법

```bash
cd restaurant-roulette
npm install
npm start
```

기본 포트는 `3001`이며, 환경변수 `PORT`로 변경할 수 있습니다.

같은 와이파이(같은 공유기)에 연결된 친구들은 서버를 실행한 컴퓨터의 사설 IP로 접속하면 됩니다. 예: `http://192.168.0.10:3001`

## 데이터 저장

`data/restaurants.json` 파일에 저장됩니다 (git에는 커밋되지 않음). 서버를 재시작해도 목록은 유지됩니다.
