# Digital Memoir — UI 조사 리포트 (Phase 1)

- **대상**: https://digital-memoir-chi.vercel.app
- **조사일**: 2026-07-19
- **담당**: 진록 (진삼 영역 대행 — 실측 도구 직접 구동)
- **방법**: 실제 렌더링 관찰. Headless Chromium(Playwright)으로 3개 뷰포트(1440·768·375) 스크린샷, DOM/computed style 추출, 성능(Navigation/Resource Timing), 접근성(대비·탭타깃·랜드마크·헤딩), 네트워크 상태코드 측정.
- **근거 자산**: `docs/research/_assets/` (스크린샷 `desktop.png`,`tablet.png`,`mobile.png`,`page-*.png`, 원측정 `audit.json`,`pages.json`,`deep.json`)

> ⚠️ **측정 환경 주의(신뢰도 확보용 기록)**: 최초 캡처 시 샌드박스에 한글/라틴 폰트가 전무하여 텍스트가 렌더되지 않았음. Nanum·DejaVu·fontconfig를 설치·재캡처하여 **실제와 동일한 렌더**를 확보한 뒤 관찰함. 따라서 아래 "사이드바 라벨 없음" 같은 폰트 아티팩트는 **버그로 보고하지 않음**(사이드바 라벨은 정상 존재). DOM 레벨 지표(예: 홈 `<main>` 텍스트 0자)는 폰트와 무관하게 유효.

---

## 0. 앱 개요 (요약은 최소화)

개인 디지털 자서전 앱. Next.js(App Router) + Tailwind, 폰트 Pretendard(본문)/Lora(세리프), `lang="ko"`.
좌측 사이드바(240px)로 **10개 섹션** 이동: 홈 · 독백 · 편지 · 자산 · 관계 · 추억 · 타임캡슐 · 타임라인 · 버킷리스트 · 설정. 모바일은 하단 탭바(홈·독백·자산·추억·메뉴) 5개 노출.

## 1. Critical (P0) — 사용자 불만의 직접 원인

### P0-1. 전 페이지에 해변 사진이 배경 전체를 100% 불투명으로 뒤덮음 ⭐ 최우선
- **실측**: `.app-bg` 요소가 `position:fixed; z-index:-1; opacity:1; background:url(/beach.jpg)`. `filter:none`(블러/오버레이 없음).
- **증상**: 홈/독백/관계/설정 등 **모든 페이지**에서 파도치는 해변 사진이 화면 전체를 채움. 콘텐츠 카드는 그 위에 반투명(rgba(248,252,254,0.6))으로 떠 있음.
- **영향**:
  - 화면 **하단 45~55%가 항상 사진만** 남는 죽은 공간 (예: `page-monologue.png`, `page-network.png` 하단 절반).
  - 사진의 밝기 편차(하늘=밝음, 물=중간톤·물보라=고휘도)가 커서 그 위 텍스트 대비가 위치마다 달라짐 → 가독성 붕괴.
  - "미완성/아마추어" 인상. **사용자 UI 불만의 핵심 원인으로 지목.**
- **근거**: `desktop.png`, `mobile.png`, `page-*.png` 전부.

### P0-2. 홈이 "빈 온보딩 화면" — 대시보드/개요 부재
- **실측**: 홈 `<main>` innerText = **0자**, heading = **0개** (`pages.json`,`audit.json`). 화면에는 사진 위에 흐린 문구 "내 인생의 기록 / 먼저 설정에서 이름과 생년월일을 알려주세요."만 중앙에 떠 있음.
- **문제**:
  - 10개 섹션의 리치한 앱인데 **첫 화면에 요약·최근기록·바로가기·진행률이 전혀 없음.**
  - CTA가 문장 속 밑줄 텍스트 링크("**설정**")뿐 — 버튼 아님. 행동 유도 약함.
  - 사진 위 흐린 텍스트라 첫인상이 "빈 페이지".
- **근거**: `desktop.png`, `mobile.png`.

### P0-3. 텍스트 대비 WCAG AA 미달 (특히 사진 위 텍스트)
- **실측(`audit.contrast`)**:
  - 홈 히어로 "내 인생의 기록" 흰색 30px — 배경(사진)과 대비 사실상 **1:1 수준**, 육안으로도 거의 안 읽힘.
  - 링크성 "설정" 흰색 18px — 대비 미달.
  - 사이드바 로고 하위 "Digital Memoir" 12px, 본문 링크 primary(rgb(28,127,184)) 18px — 4.26:1로 **AA(4.5) 미달**.
- **영향**: 100세까지 쓰는 앱 = **고령 사용자 포함**. 저대비는 치명적.

### P0-4. 배경 이미지 미최적화 (성능·비용)
- **실측(`audit.perf`)**: `beach.jpg` = **442 KB**, 전체 전송량(812 KB)의 **~54%**. 원본 JPG 단일 파일, `next/image` 미사용, 반응형/포맷(WebP·AVIF) 미대응. 375px 모바일에도 동일 대용량 전달.

## 2. High (P1)

### P1-1. 수평 공간 낭비 — 콘텐츠가 좁은 좌측 컬럼에 몰림
- 설정/독백/관계 모두 콘텐츠 카드 폭 ~500–1000px가 좌측에 치우치고 **우측 30~40%는 사진만**. 넓은 화면일수록 비대칭·허전함 심화. (`page-settings.png`)

### P1-2. 시맨틱/접근성 구조 결함
- **홈 heading 0개** (SEO·스크린리더 최상위 진입점에 h1 없음).
- 랜드마크 `aside/nav/main/nav` 존재하나 **aria-label 없음** — `<nav>`가 2개인데 구분 라벨 없어 스크린리더 혼란.
- `lang="ko"` 정상, viewport 정상. (`audit.structure`)

### P1-3. 탭 타깃 크기 미달 (WCAG 2.5.5 / 모바일 인체공학)
- **실측(`audit.viewports`)**: 데스크톱/태블릿 사이드바 링크 높이 **34px**, 모바일 하단탭 **38px** — 권장 44px 미달. 고령 사용자 오터치 위험. 데스크톱 17개 인터랙티브 중 11개가 44px 미만.

### P1-4. 모바일 하단 탭바 대비·정보량 문제
- 하단탭이 사진 위에 얹혀 **배경 서피스 대비가 약함**(물 위 아이콘). 라벨 폰트 작음.
- 10개 섹션 중 **5개만** 하단탭 직접 접근, 나머지는 "메뉴"에 숨음 — 편지/타임캡슐/타임라인/버킷리스트/관계 접근 깊이 증가. (`mobile.png`)

### P1-5. 파비콘 부재 + 콘솔 404
- `favicon.ico/svg`, `icon.png`, `apple-touch-icon.png` **전부 404**. 로드 시 콘솔 404 에러 1건 발생. 브라우저 탭·홈화면 아이콘 없음(브랜딩 손실).

## 3. Medium (P2)

### P2-1. 클라이언트 렌더 지연 — 빈 화면 깜빡임
- FCP 636ms이나 콘텐츠는 클라이언트 하이드레이션 후 렌더. JS ~341KB(약 15청크), 최대 청크 106KB. 초기엔 사진+빈 카드만 보였다가 텍스트가 채워짐(측정 중 3.5~5s 대기 후에야 `<main>` 텍스트 확보). 저사양/저속에서 "빈 페이지" 체감.

### P2-2. 타이포그래피 규칙 불일치
- `<p>`가 **Lora 세리프 · bold 700 · 18px · primary 블루**로 렌더 — 본문 문단이 파랗고 굵은 세리프라 위계 혼란. 본문(Pretendard 16/24)과 세리프(Lora) 혼용 규칙이 불명확.
- 실사용 폰트 크기 종류가 빈약(16/18/12/30px 중심) — 위계 단조.

### P2-3. 컬러 시스템 협소
- 사실상 primary 블루(28,127,184) + ink 네이비(12,45,72) 2색 + 반투명 크림 카드. 상태색(성공/경고/위험)·중립 그레이 스케일·강조색 부재로 정보 위계 표현 수단 부족.

### P2-4. 빈 상태(Empty State) 일관성은 양호하나 홈만 예외
- 독백/관계/타임라인/버킷리스트 등은 아이콘+제목+설명+CTA버튼의 **정돈된 빈 상태**를 가짐(양호). 반면 **홈만** 정돈된 빈 상태/온보딩 카드가 없음 → P0-2와 연결.

## 4. 양호한 점 (유지 권장)
- 사이드바 라벨·아이콘(lucide) 정상, 활성 상태(연블루 배경+primary 텍스트) 명확.
- 반응형 **가로 오버플로 0** (1440/768/375 모두 `overflowX:false`).
- 내부 페이지의 헤더(제목+부제)·검색·필터칩·빈상태 카드 **구성 패턴이 일관**.
- 다크모드 토글 존재(설정). 데이터 백업/CSV 내보내기 기능 제공.
