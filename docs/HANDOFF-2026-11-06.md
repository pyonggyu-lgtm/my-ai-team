## 8. 배포 중 발견한 문제 (공장 수정 필요)
- **PM2가 `ecosystem.config.js`대로 띄우면 3000 포트가 안 열림.** `server/index.js` 103줄의 "직접 실행일 때만 listen" 조건(`process.argv[1]`)이 PM2 실행기 경유라 거짓이 됨. online인데 요청 무응답, 로그도 없음.
- 서버 임시 조치(현재 동작 중, `pm2 save`됨):
  `pm2 start /usr/bin/node --name hanjan --interpreter none --time -o /srv/hanjan-data/logs/hanjan-out.log -e /srv/hanjan-data/logs/hanjan-error.log --max-memory-restart 300M --kill-timeout 5000 -- --env-file=.env server/index.js`
  (이 방식은 ecosystem의 `NODE_ENV=production`, 재시작 정책 일부가 빠져 있음)
- 공장 지시(진서): ecosystem.config.js를 `script: "/usr/bin/node", interpreter: "none", args: "--env-file=.env server/index.js"`로 수정, 배포안내 6장 맞추기, PM2 경유 포트 열림 시험 추가 → "커밋해도 됨".
- 수정 커밋 후 서버: `git pull` → `pm2 delete hanjan` → `pm2 start deploy/ecosystem.config.js` → health 확인 → `pm2 save`.
- 참고: 브라우저 SSH에 여러 줄(`\` 이어 쓰기)을 붙이면 줄 사이에 빈 줄이 끼어 명령이 끊김 → 명령은 한 줄로.
